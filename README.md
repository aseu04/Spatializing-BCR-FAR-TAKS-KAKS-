# Spatializing BCR-FAR (TAKS-KAKS)
A small interactive 3D prototype exploring how TAKS (Building Coverage Ratio – BCR) and KAKS / Emsal (Floor Area Ratio – FAR) translate into physical space, with a focus on human scale and spatial perception.
## About
This is a small experimental project I created to better visualize BCR and FAR values in three-dimensional space.

Planning decisions are often expressed through numerical values, but it can be difficult to imagine what these values actually mean spatially. This prototype is an attempt to make that relationship more tangible.

The prototype allows users to explore different building conditions in a simple 3D environment. Human and tree figures are included as scale references, while the first-person view allows users to experience building height and spatial proportions from a human perspective.

To reflect real-world parameters, the simulation dynamically restricts the maximum number of allowable floors based on the selected building structural type (e.g., timber, masonry, or reinforced concrete), strictly in accordance with Turkish zoning regulations.

## Purpose
The main purpose of this experiment is to explore the relationship between numerical planning values and human-scale spatial perception.

Rather than understanding TAKS and KAKS only as numerical values, the prototype aims to make it easier to visualize what these values may mean in physical space.

## Development
AI tools were used as technical assistance during the coding process. The concept, purpose, spatial approach, and desired features of the prototype were defined by me.

This project is currently a simple experimental prototype created as part of a personal exploration of spatializing planning values.
